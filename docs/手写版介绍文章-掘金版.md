# 给大家介绍一个我做的一个coding工具zen-gitsync

大家好，给大家介绍一个我做的一个coding工具zen-gitsync。

- GitHub：https://github.com/xz333221/zen-gitsync
- npm：https://www.npmjs.com/package/zen-gitsync

> 如果觉得有点意思，欢迎去 GitHub 点个 star ⭐，这就是对我最大的支持了。

## 一键提交

这个工具叫这个名字，是因为最开始的时候，我是拿它作为一个一键 Git 提交工具去做的。当时觉得 add 加 commit 加 push 的 Git 操作好麻烦，为啥不能直接一键提交呢？于是就有了这个工具，工具的用法很简单，全局安装之后，在终端输入字母g，会自动展示出git状态及diff内容，输入要提交的内容并回车即可完成提交。

![一键提交（终端输入 g）](https://zen-gitsync.flowdash.cn/shots/cli-quick-commit.png)

## 工作台

但是随着时间的发展，这个工具的功能逐渐变多，所以从最初的命令行逐渐发展出了 UI 界面的功能操作。我现在使用这个工具，主要是用它的编程工作台的一个功能。这个功能能让你总览你的各个项目，然后同时进行并行开发。并监督不同项目各个任务的执行情况。我目前做了三种执行器工具的任务派发功能，ClaudeCode、 Codex 以及 OpenCode。

![工作台：多项目编排台](https://zen-gitsync.flowdash.cn/shots/workbench-board.png)

## 内置智能体

我内置了一个简单的g ai智能体在里面。任务的派发，既可以使用手动派发，就是说你可以选择手动选择执行器进行任务派发。也可以使用 Agent 去进行派发，也就是我内部集成的这个 GAI 智能体，我做这个，其实就是在这个智能体里加了一个任务派发的工具。这个智能体现在可以在终端和g ui中去使用

![内置智能体 g ai（终端版）](https://zen-gitsync.flowdash.cn/shots/agent-cli.png)

![内置智能体 g ai（g ui 版）](https://zen-gitsync.flowdash.cn/shots/agent-gui.png)

然后这个系统提供了对远程仓库的连接功能，连上之后可以让它知道你远程有哪些项目。然后你就可以跟它说，找一下哪个项目，克隆下来，改一下什么并提交。我这个智能体是可以装 Skill 或者 MCP 的，也可以派发使用执行器执行的任务，或者是派发定时任务。

## Git提交页面

g ui进入之后的初始页面是Git的总览页面，里面内置了Git的各种功能以及快捷提交

![Git 提交页面](https://zen-gitsync.flowdash.cn/shots/git-commit-view.png)

## 文件空间

文件空间也是我常用的一个工作板块，我是把它当成笔记系统来用的。在这里可以预览不同类型的文件；对于 Markdown 文档，还可以直接复制内容，粘贴到不同的发布平台进行内容发布（点击复制富文本）。同时能与内置的 Agent 进行对话，可以问任何关于已打开文件的问题，或者去执行一些操作。

![文件空间：Markdown 预览与复制富文本](https://zen-gitsync.flowdash.cn/shots/file-space.png)
