# 一个字母「g」，承包了我所有的 Git 操作

> 备选标题：
> 《我用 1900 次提交，把 Git 变成了一句话的事》
> 《从 g 到 g ai：我的 Git 工作流只用一个工具》
> 《提交别说废话：Git 自动化工作台 zen-gitsync》

---

每天写代码最磨人的往往不是写，而是提交。`git add`、`git commit`、`git push`，同一天重复几十次；提交信息写到词穷，最后敲一个"fix"敷衍了事；想同步文件夹要自己写脚本、挂计划任务；排查线上问题时更是在终端里把命令一个一个来回敲。

2024 年底我开始动手做一个工具，把这些围绕 Git 的机械劳动收起来。一年半、1900 多次提交之后，它迭代成了现在的 **zen-gitsync**——npm 上月下载 7000+，版本来到 v2.16。这篇文章不堆功能列表，只讲我真正每天都在用的几个能力。

![Git 选择模式——勾选文件后暂存、提交、推送自动限定在所选范围](screenshots/article/01-git-selection.png)

## 一个字母 g，搞定暂存提交推送

安装一行 `npm install -g zen-gitsync`，然后得到一个全局命令：**g**。任何仓库里敲 `g`，回车就自动暂存、提交、推送，提交信息交互输入。省心用 `g -y` 全程无交互，带信息用 `g -m "修复引导弹窗"`。这套极简命令组合起来，覆盖了我每天 80% 的提交动作。

## AI 生成提交信息 + 选择模式

GUI 里我最顺手的是提交表单顶上的 **AI 生成** 按钮。不生硬地调用一次大模型，而是基于当前暂存的 diff 直接生成符合 Conventional Commits 规范的提交信息，填进类型、作用域、描述栏。不用切窗口，点一下就好。

真正让手感变好的是**选择模式**：在文件列表勾选几个文件后，"AI 生成"和"一键提交所选""一键推送所选"会自动只作用于这几项，不再暂存整个工作区。改完两个文件，勾选它们，AI 推断用途，直接推送——不再有"全选→提交"的走神时刻。

![AI 生成提交信息——基于勾选的 diff 生成 Conventional Commits 信息](screenshots/article/02-git-ai-commit.png)

## g ai：在 pod 里排查问题

服务器上出了问题，最不想做的就是拷贝一堆日志回本地。我的办法是在 pod 里直接 `g ai "帮我看下最近这个服务的 ERROR 日志"`——它是一个跑在终端里的 AI agent，能直接调命令、读文件、改代码、提交，排查完给结论，不用来回粘日志。

GUI 里附带一个**智能体**页面，和终端会话统一管理：终端 `g ai` 开的会话会在 Web 端标一个 CLI badge，Web 开的也能在终端继续。排查时用终端直接动手，复盘时用 Web 智能体继续追问，两个入口接同一份对话，是我在容器里最常用的工作姿势。

![智能体欢迎页——终端与会话 Web 端统一管理](screenshots/article/03-agent-welcome.png)

## 定时同步 + 开机自动跑

几个常用目录要跟着多台机器同步，我不想每次都记得。`g -y --interval=1800` 每 30 分钟自动提交推送当前目录，再配合 `scripts/start-sync-on-boot.ps1` 最小化后台启动几个仓库，把脚本的快捷方式丢进 Windows 的开机启动文件夹。从此写笔记、改配置、关盖走人，同步自动发生。

控制台页面里保存的命令（dev、pull、release 等）跑在同一套机制上——定义一次，GUI 点一下就在独立终端会话里跑它；项目启动项能让打开仓库时自动跑一串命令或流程。我把这块当成"开工自动化"，每天省掉几个重复动作。

## 可视化流程编排：多项目脚本顺序执行

单条命令不够用的时候，我用**可视化编排**来串流程。拖拽节点：命令节点跑一个已保存的自定义命令，等待节点暂停 1–3600 秒，版本节点给 `package.json` 打 patch/minor/major，还有条件分支、用户确认、用户输入等。节点按拓扑顺序执行，流程保存了可以二次编辑。

作者搭过一个"每日构建流"：更新依赖 → 等待落盘 → 构建 → 部署 → 版本 +1。整套流程画一次，之后点执行就行。页面左侧列出已保存编排和节点工具箱，右侧是画布。多项目的脚本顺序执行，被压成了一个流程图——这大概是我最喜欢 GUI 的地方。

写长文、做方案之前，我先在思维导图页里把结构搭起来，支持 Markdown 双向导入导出，根的每条分支都能折叠展开。先在图上改结构，想清楚再落笔正文，比直接开文档低头写顺畅得多。

## 诚实说一下源码地图

GUI 里带过一个"源码地图"，能调 AI 生成项目的依赖关系图。说实话我自己基本没打开过它——日常理解代码靠的是 GitNexus（项目本身就是用 GitNexus 索引和分析增量改动）。工具是给自己做的，没用就老老实实说没用，文章里不硬推。

## 几个在意的细节

GUI 冷启动把 Monaco、流程图、思维导图、流程图编排器等大模块拆成独立 chunk 懒加载，Git 面板首屏不再等编辑器。明暗主题在 header 一键切换，中英双语即时生效。可访问性做到 WCAG 2.1 AA，键盘可以操作全部主流程。后端不可达时全局横幅提示并支持一键重试。升级不用离开窗口——检测到新版本点一下"升级"，它自己装完、重启、并把浏览器重定向到新端口。这些不会写进功能列表，但每天都让手里的事更顺一点。

## 最后

zen-gitsync 以 Apache-2.0 协议开源。安装就在一行：

```bash
npm install -g zen-gitsync
```

然后在任意仓库试试这个字母：**g**。
